# Marylee Content Studio

Окремий застосунок для **Marylee Shop, української аудиторії та продажів в Україні**. Завантажуєш товари ввечері, отримуєш відео, фото, тексти й інструкції на наступний день. Публікуєш вручну.

**Репозиторій:** `cyfrovahata-bit/marylee-content`, гілка `main`.
**Railway:** використовуй тільки другий проєкт `YouTubeStories`.
**Google Drive:** тільки `YouTube Storis → Marylee Content`.

## Що працює

- Каталог: назва, артикул, ціна, розміри, кольори, матеріал, опис постачальника, фото й відео. Пошук, зміна порядку ракурсів, архів товарів.
- Вибір двох різних товарів на день. Автовідбір дає паузу 7 днів перед повтором; її можна змінити. Ручний вибір дозволяє використати товар раніше.
- Окремі редакційні завдання для поради, каруселі, деталі, знайомства та продажу. Reel: опис разом із короткими параметрами до 250 символів, 15–20 ключових слів, п’ять малих хештегів; сторіз до 90 символів. Оптові ціни, контакти постачальника та службові нотатки вилучаються з контексту ШІ. Генерація українських текстів через OpenAI з фото як контекстом для відбору ракурсів. Історія підписів зберігається, близькі повтори відхиляються. Параметри товару та ціна додаються з каталогу.
- Монтаж MP4 1080×1920 з готового відео або фото, субтитри, JPG-обкладинка та SRT. Товарний Reel — чотири короткі сцени без голосу, навіть коли озвучка порад увімкнена. Ранковий Reel — жвава українська озвучка OpenAI Marin; голос можна перевизначити лише змінними Marylee.
- Ранковий Reel автоматично отримує редакційну ШІ-ілюстрацію з двома конкретними образами: порівняння, лівий образ, правий образ, висновок. Фото монтуються у відео з рухом та субтитрами. Одна ілюстрація спільна для Reel і денного опитування. Власні матеріали можна вибрати в редакторі.
- Каруселі 1080×1350, сторіз 1080×1920. Опитування отримує фон, запитання й дві відповіді; справжню наліпку додаєш у Facebook/Instagram самостійно.
- Календар: переглянути, завантажити, скопіювати весь підпис, відредагувати, повністю перегенерувати окремий матеріал (текст, відбір фото, ілюстрація, монтаж, обкладинка) або окремо оновити текст чи монтаж, пропустити, позначити опублікованим.
- ZIP дня з файлами у папках за часом, текстами, сценаріями й покроковими інструкціями. За бажанням — копія ZIP на Drive.
- ШІ студія: окремі редакційні ілюстрації через Images API або завантаження своїх матеріалів. Ранкова ілюстрація створюється автоматично; додаткові можна створити вручну. Результат зберігається перед озвучкою, тому повтор після збою не створює його вдруге.
- Черга завдань, прогрес, відновлення після збою, кеш озвучки, добові обмеження запитів. Після перезапуску перерваний платний запит не повторюється самостійно.
- Прямий доступ за посиланням, без входу та пароля. Каталог, історія, завдання й файли зберігаються на **окремому Railway Volume**.

За рішенням власника авторизацію прибрано. Кожен, хто відкриє адресу застосунку, може переглядати й змінювати каталог, завантажувати файли та запускати генерацію за серверними API-ключами в межах налаштованих лімітів. Самі ключі у браузер не передаються.

## Запуск на Railway — по черзі

1. Відкрий **`YouTubeStories`**, перевір назву проєкту у верхній панелі. Працюючий `TikTok Channel` не перемикай.
2. Додай до сервісу **окремий Volume**, mount path **`/data`**. Не використовуй спільний Volume першого каналу. Для цього застосунку потрібна одна репліка сервісу.
3. У Variables другого сервісу додай/перевір:

| Змінна | Значення |
|---|---|
| `MARYLEE_DATA_DIR` | Необов’язкова: шлях підключеного Volume визначається автоматично. Якщо задаєш вручну — `/data` або папка всередині Volume |
| `PUBLIC_URL` | HTTPS-адреса саме цього сервісу, без `/` наприкінці; можна залишити порожньою |
| `OPENAI_API_KEY` | Ключ OpenAI API з балансом і доступом до потрібних моделей |
| `MARYLEE_DRIVE_PARENT_ID` | `1sIcjn1IYI4uuw6TsBwyiKUKN6eNQUpXJ` |
| `GOOGLE_OAUTH_CLIENT_ID` | Із другого сервісу, якщо доступ до його Drive вже працює |
| `GOOGLE_OAUTH_CLIENT_SECRET` | Із другого сервісу |
| `GOOGLE_OAUTH_REFRESH_TOKEN` | Із другого сервісу, з доступом до Drive |
| `MARYLEE_TTS_ENGINE` | `openai` за замовчуванням; `elevenlabs` лише за явного вибору |
| `MARYLEE_OPENAI_VOICE` | `marin` за замовчуванням |

Для ElevenLabs потрібні `ELEVENLABS_API_KEY` і `TTS_ELEVEN_VOICE_ID`. За замовчуванням його модель — `eleven_multilingual_v2`; можна задати `TTS_ELEVEN_MODEL`. Ключі не додавай у GitHub або чат.

4. У **Settings → Source** другого сервісу підключи `cyfrovahata-bit/marylee-content`, гілку **`main`**. Root Directory — корінь. Старий ручний Start Command очисти або постав `node src/server.js`. Dockerfile і `railway.json` уже в репозиторії.
5. Дочекайся успішного deploy. `/healthz` має відповідати `app: marylee-content`. Відкрий адресу сервісу: майстерня доступна одразу, без входу.
6. У **Налаштуваннях** натисни **«Підготувати папки Marylee»**, якщо використовуватимеш Drive. Застосунок створить власні підпапки в `YouTube Storis`. Інші файли там не видаляються.
7. Додай два товари й натисни **«Сформувати день»**. Перевір перший комплект зі звуком перед публікацією. Автопідготовка наступного дня за замовчуванням — **22:30 за Києвом**; у налаштуваннях її можна вимкнути.

Окремого Telegram-бота для роботи не потрібно: застосунок відкривається у браузері телефона. Якщо користуєшся кнопкою Mini App другого бота, її URL може вести на адресу цього сервісу. Цей код не запускає `getUpdates` і не використовує токени соцмереж.

### Якщо після заміни репозиторію deploy впав

Саме підключення нового репозиторію не додає Volume. Відкрий невдалий deployment другого сервісу та **Deploy Logs**. Якщо процес не дійшов до запуску — дивись **Build Logs**.

| Повідомлення | Що зробити тільки в `YouTubeStories` |
|---|---|
| `Додай до цього сервісу окремий Railway Volume` | Підключити Volume, mount path `/data`. Не вписувати `RAILWAY_VOLUME_MOUNT_PATH` вручну: Railway додає її при справжньому монтуванні |
| `MARYLEE_DATA_DIR має бути всередині` | Прибрати `MARYLEE_DATA_DIR` для автоматичного визначення або узгодити її з mount path Volume |
| `Cannot find module ... web/server.js` | Перевірити, що використовується `main` нового репозиторію, а Start Command — `node src/server.js` |
| `No such built-in module: node:sqlite` | Перевірити використання Dockerfile з Node 24 замість старого середовища збірки |

Після збереження налаштувань запусти новий deploy. Постійне сховище обов’язкове для робочого сервісу; OpenAI, ElevenLabs і Drive можна налаштувати після запуску. Стару змінну `MARYLEE_ADMIN_PASSWORD`, якщо вона залишилася на Railway, застосунок ігнорує. Відсутній Volume не замінюється тимчасовою папкою.

## Щоденний порядок

1. Увечері відкрий **Каталог → Додати товар**.
2. Встав назву й опис, заповни відомі параметри, додай фото/відео. Дочекайся повідомлення «Товар збережено».
3. Додай другий товар або використовуй раніше завантажені позиції. Не треба завантажувати весь каталог повторно.
4. Натисни «Сформувати день» для негайної підготовки або дочекайся 22:30. Без API-ключа можна створити тільки розклад, внести тексти вручну й вимкнути озвучку.
5. Наступного дня відкривай матеріали по черзі, завантажуй файли, копіюй підпис, виконуй інструкцію. Після публікації натискай «Опубліковано».

| Час, Київ | Матеріал |
|---|---|
| 09:00 | Корисний Reel із прикладами образів |
| 09:30 | Поширення ранкового матеріалу у сторіз |
| 12:00 | Сторіз з опитуванням |
| 14:00 | Карусель товару A |
| 15:30 | Деталь товару A у сторіз |
| 18:30 | Знайомство з товаром B у сторіз |
| 19:30 | Reel товару B |
| 20:00 | Поширення вечірнього Reel у сторіз |
| 21:30 | Додаткова сторіз, вимкнена за замовчуванням |

Базово: **3 дописи в стрічку і 5 сторіз**, із додатковою — 6 сторіз. За одного товару він використовується ввечері, а вдень готується корисний фотопост. Це стартовий тест графіка, а не гарантія охоплень. Не дублюй ті самі публікації паралельним кроспостингом.

## Імпорт із Google Drive

Після створення папок відкрий посилання «Папка товарів» у налаштуваннях. Кожному товару — окрема підпапка з фото/відео й `product.json`:

```json
{
  "name": "Сукня міді",
  "sku": "285",
  "price": 1290,
  "sizes": "S, M, L",
  "colors": "Чорний, молочний",
  "material": "Склад із етикетки",
  "description": "Опис постачальника",
  "notes": "Показати застібку та інший ракурс",
  "active": true
}
```

Це приклад формату, не реальні дані товару. Невідомі поля пропусти. Альтернатива — `опис.txt`, тоді ціна, розміри й матеріал заповнюються в каталозі вручну. Програма не вгадує їх із вільного тексту.

Папка імпортується після **10 хвилин без змін у її файлах**. Це дає завершити завантаження. Імпорт викликається кнопкою або кожні 15 хвилин, якщо увімкнено налаштування. Повторний імпорт не дублює ідентичні файли. У UI і Drive не редагуй один товар одночасно; зміна `product.json` оновлює відповідні поля каталогу.

## Важливі межі

- Соціальних публікаторів у цьому застосунку немає. Позначка «Опубліковано» — твій ручний запис, а не виклик Facebook/Instagram API.
- Звичайне відеослайдшоу з фотографій не слід вважати форматом для монетизації Meta. Монетизація редакційного відео також не гарантується.
- Сценарії й тексти потрібно переглядати: ШІ може помилитися. Історичний сюжет можна ввести вручну після перевірки джерел; вбудована автоматична підбірка складається з порад і наочних прикладів стилізації, без автоматичного пошуку історичних фактів.
- Синтетична озвучка позначається у повному підписі. Нативні позначки ШІ та опитування додай у соцмережі, коли це потрібно.
- Генератор ілюстрацій створює **редакційні зображення**, не змінює фото реального одягу. У каталог завантажуй матеріали, які достовірно показують товар і які ти маєш право використовувати.
- Пісні з трендів не завантажуються. Їх можна додати вручну в соцмережі з урахуванням її правил.
- Розрахунковий бюджет за замовчуванням $5/день — це облік резервів за настроюваними оцінками, не гарантований рахунок провайдерів. Тверді межі програми: 24 текстові запити, 2 ілюстрації та 10 000 символів озвучки на київську добу. Змінні оцінок є у `.env.example`; при зміні моделі перевір оцінки. Для обмеження фактичних витрат використовуй також доступні засоби провайдера.
- Невдалий платний запит теж зберігає резерв: його фактична оплата може бути невідомою. Перегенерація тексту потребує нового запиту; однакова озвучка береться з кешу.
- Потрібен окремий постійний Volume. Його видалення призведе до втрати локального каталогу й оригіналів, завантажених через форму. ZIP на Drive містить готовий день; це не повна резервна копія каталогу. Налаштуй резервні копії Volume у Railway.

## Локальний запуск і перевірки

Потрібні Node.js **24**, FFmpeg з libass і libx264, шрифт DejaVu Sans, `zip`, `unzip` для тестів. NPM-залежностей немає.

```bash
node src/server.js
node scripts/check.js
node --test test/*.test.js
```

Локально сервер за замовчуванням слухає loopback, у production — усі інтерфейси. Авторизації немає в обох режимах. Платні API не викликаються тестами: перевіряються контрольовані відповіді провайдерів, а монтаж FFmpeg і ZIP виконуються насправді.
